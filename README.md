# 校集：通达校园 Agent 平台

当前版本说明，核对日期：2026-09-24。面向南京邮电大学通达学院，生活查询默认学校周边3公里，最多5公里。

## 启动

双击本目录「打开原型.cmd」。如果服务已运行，会直接打开页面；否则启动本机后台，使用期间保持启动窗口打开。也可以在本目录运行 `node server.cjs`。

在浏览器访问 http://127.0.0.1:4173 。不要直接打开dist/index.html，本版本需要后台。当前服务仅监听本机地址，尚未部署为全校可访问的网站。

## 直接问生活助手

进入「校园生活助手」，可以问：

- 通达附近有什么吃的？
- 学校旁边哪里喝咖啡？
- 学校周边5公里哪里看展？
- 学校附近哪里打印？`n- 学校附近哪里有快递点？`n- 通达两公里内哪里洗衣？
- 通达外卖能送到宿舍楼下吗？

明确的周边地点问题会自动查询本机公开地点库，不必先操作地图表单。也可以使用「通达周边吃喝玩乐」表单查询，再勾选参考本次结果。默认查询中心是学校公开地图代表坐标，不获取用户个人定位。

已配置豆包时，勾选云端发送确认后提问；发送内容包括当前问题、相关资料和匹配的地点片段。地点搜索本身不调用地图接口，豆包回答仍计入模型调用。没有配置豆包也可以使用地点搜索与本地资料检索。

结果中的距离为直线距离，不是校门出发的步行距离。校园区域提示依据社区地图推测，不表示已确认允许进入、可以代收快递或正在营业。未收录不等于附近没有。价格、优惠和实时营业状态尚未接入。

## 提交资料

进入「资料贡献」，填写标题、目标助手、来源及正文摘要。原文链接、发布日期、采集日期分别填写；不知道原发布日期就留空，不要用今天代替。选择「官方通知」「个人体验」「商家宣传」或「未确认」。

抖音、小红书资料需保留原帖链接与时间，并在内容中说明具体门店、与通达周边的关系以及哪些事实尚未核实。粘贴链接只会保存来源，不会自动抓取网页。TXT/MD可以读取文字；PDF/DOCX目前需要手工填写摘要，原文件不会存入知识库。

提交的内容默认待审核，不参与回答。只有通过审核的资料可以进入知识问答；社区地图点位另标来源，不能冒充学校审核资料。

## 审核与团队

右上角可切换演示身份。管理员在「审核管理」查看正文、来源链接、日期和内容性质，确认后通过或填写原因驳回。被驳回的资料由提交者修改重提，仍需重新审核。下架资料保留在后台，但退出检索。

演示身份里的团队成员只有一个入口。在「团队工作台」统一维护生活、办事和学习助手，填写职责与回答规则，提交后由管理员审核上线。

当前身份切换用于本机演示，不是真实账号登录或适合开放互联网的权限体系。现有版本适合在自己电脑上测试项目流程。

本机预览默认仍可切换演示身份，Mac 上打开 http://127.0.0.1:4173 的演示不受影响。面向公网时，在 config.local.json 写入 `"publicMode": true` 或 `"demoIdentities": false`（启动前设置环境变量 `PUBLIC_MODE=1` 效果相同）。这样会关掉演示身份下拉，并拒绝 `/api/session` 切换，访问固定在同学端。两项都没关时保持本机演示可用。字段示例见 config.example.json。同学端状态只显示「模型已连接」，不显示豆包品牌。

## 当前数据与保留方式

已审核资料共209条：生活37、学习78、办事94。学校周边公开地点59个；其中部分位于邻校内部，查询时显示已核对的地图区域线索。

公开来源与导入记录在imports目录。旧的全扬州地点快照保留为归档，当前生活助手使用通达周边数据；较远生活资料已下架。

知识库保存在data/store.json，地图资料保存在lib/places-osm.json，校园区域资料在lib/campus-areas.json。模型密钥由本机 config.local.json 保存，这是本地机密，不要公开分享，也不要提交到仓库。同步或更新只覆盖程序文件（dist/、lib/、tests/ 等），不要覆盖、删除或改写 config.local.json；启动脚本也不会动它。服务重启后，已经保存的密钥仍然有效，不必重新填写。备份知识资料时可先停止服务，再复制 data、lib 与 imports 目录，密钥文件单独保管。

不要随意点击「重置演示数据」：它会恢复初始演示资料，并清除后续导入内容，不是刷新页面。
