# 校集

面向南京邮电大学通达学院的校园 Agent 原型：生活查询、办事与学习资料问答、同学互助。仓库是公开源码。克隆下来能在本机跑起来的，是你检出的那一版，不是「已经全校上线的最新界面」。

## 启动

双击本目录「打开原型.command」（Windows 副本为「start-preview.cmd」）。如果服务已运行，会直接打开页面；否则启动本机后台，使用期间保持启动窗口打开。也可以在本目录运行 `node server.cjs`。

在浏览器访问 http://127.0.0.1:4173 。不要直接打开dist/index.html，本版本需要后台。当前服务仅监听本机地址，尚未部署为全校可访问的网站。

## 进入平台（2026-11-19 起）

打开根地址后先看到全屏照片开场页：照片约 5 秒自动轮换，页面上没有左侧仪表盘、汉堡按钮和导航。照片底部显示「请点击任意键进入平台」；点击画面任意位置或按任意键进入独立登录页，登录页同样不显示左侧仪表盘。登录或注册成功后进入平台仪表盘（学生默认落在互助通达，其他演示身份落在找助手），左侧导航恢复。已登录时再打开开场页，点击会直接进入仪表盘。

照片放在 `data/homepage-posters/`（已被 `.gitignore` 排除，不随仓库分发），至少放 `01.jpg`、`02.jpg` 两张授权照片；目录为空时使用渐变占位继续轮换，缺图不会影响服务启动。

## 直接问生活助手

进入「校园生活助手」，可以问：

- 通达附近有什么吃的？
- 学校旁边哪里喝咖啡？
- 学校周边5公里哪里看展？
- 学校附近哪里打印？
- 学校附近哪里有快递点？
- 通达两公里内哪里洗衣？
- 通达外卖能送到宿舍楼下吗？

明确的周边地点问题会自动查询本机公开地点库，不必先操作地图表单。也可以使用「通达周边吃喝玩乐」表单查询，再勾选参考本次结果。默认查询中心是学校公开地图代表坐标，不获取用户个人定位。

已配置豆包时，勾选云端发送确认后提问；发送内容包括当前问题、相关资料和匹配的地点片段。地点搜索本身不调用地图接口，豆包回答仍计入模型调用。没有配置豆包也可以使用地点搜索与本地资料检索。

结果中的距离为直线距离，不是校门出发的步行距离。校园区域提示依据社区地图推测，不表示已确认允许进入、可以代收快递或正在营业。未收录不等于附近没有。价格、优惠和实时营业状态尚未接入。

## 互助通达与求助通达

同学之间可以互相登记「我能帮忙」或「我需要帮忙」：类型自己写，登记时选择生效时段或长期，过期或下架后自动退出匹配。左侧仪表盘把浏览和发布分成两个入口：「互助通达」（`#board`）用来浏览同学们正在生效的求助和互助信息；「求助通达」（`#help`）用来登记问题、查看我发布的求助和别人发来的消息。发布和开聊需要学号登录（本机演示账号，不是学校真实认证），联系方式由发布者自愿公开。发布者会在「求助通达」的「别人发来的消息」里看到私聊和未读数并直接回复，停留在这个页面时会定时刷新；私聊页不显示双方学号。登记可以被其他同学举报，管理员在「审核管理」的「互助举报」里选择下架或忽略。发布、提问、私信和登录都有本机内存限流（重启服务后清零）。目前只有少量测试数据，尚未面向同学开放。

互助登记与私聊不做发布前人工审核；提交时会自动做内容安全检查，命中违规内容即拒绝且不保存。旧的「发布前审核」代码仍保留为实验开关（`BOARD_REVIEW=1`，默认关闭，界面不提示）。

## 启动

仓库没有第三方依赖。`package.json` 只有名字和 `start` 脚本，没有 `dependencies`，也没有 `engines`。不要为了启动去跑 `npm install`。

```bash
node server.cjs
```

然后打开 http://127.0.0.1:4173 。页面来自 `dist/`，直接双击 `dist/index.html` 或仓库根目录的 `index.html` 都不是这套服务。Mac 上的 `打开原型.command` 只是执行 `node server.cjs --open`。

未设置 `HOST`、也不在 Render 上时，进程只听 `127.0.0.1`。端口默认 `4173`，可用环境变量 `PORT` 改。

2026-10-20 的旧迁移说明写过「Node.js 18 或更高版本」。那是旧提示，不是已经测过的最低版本。本文写作时在 Node `v22.23.4` 上跑过测试，见 [docs/onboarding/07-快速启动与测试.md](docs/onboarding/07-快速启动与测试.md)。
