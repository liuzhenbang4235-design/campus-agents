# 协作与待办

## 怎么提交改动

1. Fork [campus-agents](https://github.com/liuzhenbang4235-design/campus-agents)。
2. 文档或 `main` 上已有行为：从最新 `main` 开分支。海报首页、菜单、独立登录：从 [PR 26](https://github.com/liuzhenbang4235-design/campus-agents/pull/26) 的 `cursor/cinematic-home-menu-84e7` 最新头另开功能分支。2026-11-15 的头是 `2532c11`，以 PR 页面为准。
3. 跑 [07-快速启动与测试.md](07-快速启动与测试.md) 里的命令，在说明里写提交号和 Node 版本。
4. 开 pull request 到对应的基线。维护者审核前不要合并。

合并进 `main` 可能让跟踪 `main` 的正式站自动部署。产品代码和这份文档都等维护者看过再合。不要为了文档把 PR 26 合进 `main`。

这次不发送仓库邀请，不修改分支保护，不添加 LICENSE，不添加 GitHub Actions。
