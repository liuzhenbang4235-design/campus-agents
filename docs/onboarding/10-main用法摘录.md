# main 上的用法摘录

适用于 `main`（2026-11-15 的 `53e64e93`）以及按这个分支部署的正式站。海报首页和独立登录页不在这一版。操作细节来自仓库里 2026-10-27 的说明，并按同一天读到的代码改过已经过期的数字。

## 生活助手

进入「校园生活助手」后可以直接问周边吃什么、咖啡、看展、打印、快递、洗衣、外卖能否到宿舍楼下。明确的周边问题会查本机公开地点库。默认中心是学校公开地图上的代表坐标，不读取个人定位。

也可以用「通达周边吃喝玩乐」表单，再勾选把本次结果交给模型。配置了云端模型时，勾选确认后才会发送；发送内容包括问题、相关资料和匹配的地点片段。没有云端密钥时，地点搜索和本地检索仍可用。

距离是直线距离。校园范围是地图线索，不表示已经确认可以进入、可以代收或正在营业。未收录不等于附近没有。价格、优惠和实时营业状态没有接入。地点快照见 `lib/places-osm.json`：2026-09-23，59 条，范围写明是代表坐标周边 5 公里内的部分地点。

## 互助通达

可以登记「我能帮忙」或「我需要帮忙」。类型自己写，选择生效时段或长期，过期或下架后退出匹配。提问按语义匹配当前生效的登记，同意之前不开对话。

在 `main` 上，发布和开聊需要学号登录（本机 8 位学号账号，不是学校认证）。提问不用登录。联系方式由发布者自愿填写。私聊页不显示双方学号。登记可以被举报，管理员在「审核管理」里处理。

发布、提问、私信和登录有进程内限流，重启后清零。登记和私聊提交时做内容安全检查，命中则拒绝且不保存。旧的发布前审核开关是环境变量 `BOARD_REVIEW=1`，默认关闭。

本地词表可用 `BOARD_BLOCK_KEYWORDS` 追加，用 `BOARD_MODERATION=0` 关闭检查。模型检查会把登记或私聊文本发给已配置的云端模型。

## 资料、审核、演示身份

「资料贡献」填写标题、目标助手、来源和正文摘要。原文链接、发布日期、采集日期分开填。不知道原发布日期就留空。来源性质选「官方通知」「个人体验」「商家宣传」或「未确认」。

粘贴链接只保存来源，不会自动抓取。TXT、MD 可以读入文字。PDF、DOCX 需要手工填摘要，原文件不进知识库。提交默认待审，通过后才参与回答。

右上角可切换演示身份。这是本机演示，不是真实权限。面向公网时在未跟踪的 `config.local.json` 写 `"publicMode": true` 或 `"demoIdentities": false`，或在启动前设置 `PUBLIC_MODE=1`。正式站的 Blueprint 把 `PUBLIC_MODE` 设为 `1`。本机预览不要设这项。

## 数据在哪里

克隆后的知识种子是 `lib/seed.json`：4 个助手、4 篇虚构示例。2026-10-28 说明里的「已审核 218 条」是维护者本机私有库的计数，那份 `data/store.json` 不在 Git 里，新克隆不会带上。

地图在 `lib/places-osm.json`，校园范围在 `lib/campus-areas.json`。运行后的知识库、互助数据和密钥文件都在被忽略的 `data/` 与 `config.local.json`。不要把它们提交上来。不要随意点「重置演示数据」：它会把知识库恢复成种子，并清掉之后导入的内容。

## 部署注意

本机默认只听 `127.0.0.1`。校内部署见 [deploy/README.md](../../deploy/README.md)：反向代理保留 Host，转发 `X-Forwarded-Proto`，并设置 `CAMPUS_ORIGINS`。Render 的临时做法见 [deploy/render.md](../../deploy/render.md)：`HOST=0.0.0.0`，用 `ACCESS_USER` / `ACCESS_PASSWORD` 做一层共享密码。那是自定义域名和另行决定的访问控制之前的过渡，不是学校统一认证。共享密码的值不要写进仓库。

`/api/session` 在公开模式关闭之前仍可切换管理员演示身份。未接真实登录时，只放在本机、内网，或再加一层由维护者另行决定的访问控制。
