# 架构与目录

根据 2026-11-15 读到的 `main`（`53e64e93`）整理。PR 26 的差别写在最后，依据是同一天的 `2532c11`，不是推测。

## 进程怎么跑

`server.cjs` 调用 `lib/backend.cjs` 的 `createApp`，然后 `listen`。

- 端口：`PORT`，默认 4173。
- 地址：设置了 `HOST` 就用 `HOST`。没设 `HOST` 且 `RENDER=true` 时用 `0.0.0.0`。其他情况用 `127.0.0.1`。只设 `PORT` 不会改成公网监听。
- 静态文件只从 `dist/` 提供四样：`/` 与 `/index.html` → `dist/index.html`，以及 `app.js`、`places.js`、`styles.css`。
- 仓库根目录的 `index.html` 和 `site-dist/index.html` 是「生成投稿文件并下载」的静态表单，`server.cjs` 不提供它们。`.openai/hosting.json` 把静态目录指到 `dist/`，它不是这套 Node 服务，也不是正式站的域名证明。

`package.json` 没有 `dependencies`、没有 `engines`、没有 lockfile。`render.yaml` 的构建命令是 `node --check server.cjs`，启动命令是 `node server.cjs`，并设置 `SKIP_INSTALL_DEPS=true`。健康检查路径是 `/api/health`，返回 `{"version":2,"app":"campus-agent"}`。

## 请求进了哪里

`lib/backend.cjs` 用 Node 自带的 `http` 处理 `/api/*`，其余路径按上面的静态表。主要模块：

| 文件 | 作用 |
| --- | --- |
| `lib/retrieval.cjs` | 从已审核资料里检索片段 |
| `lib/provider.cjs` | 可选云端模型。服务商为通义千问、DeepSeek、豆包，或本机配置的 HTTPS 自定义地址 |
| `lib/places.cjs` | 地点查询。有高德 Key 时走高德；否则使用本地快照 |
| `lib/local-places.cjs` | 读 `lib/places-osm.json` |
| `lib/campus-intent.cjs` | 从问句里取周边查询。默认半径 3000 米，问句写明 1–5 公里时改用该值 |
| `lib/campus-area.cjs` | 读 `lib/campus-areas.json`，给地点一个校园范围线索 |
| `lib/source-metadata.cjs` | 来源、发布日期、采集日期、内容性质 |
| `lib/moderation.cjs` | 互助和私信的本地词表，以及可选的模型语义检查 |
| `lib/campus-board.cjs` | 账号、登记、匹配、私信、举报。密码用 scrypt 哈希 |
| `lib/seed.json` | 首次没有知识库文件时的种子：4 个助手（新生入学助手为待审）、4 篇标题带「虚构示例」的资料 |

前端在 `dist/app.js`，用地址栏 hash 切换找助手、对话、互助、贡献、团队工作台和审核。`dist/places.js` 是生活助手的查询表单。

`main` 的登录是页面里的「学号登录」弹框，以及互助页里嵌的同一张表。接口是 `POST /api/auth/register` 和 `POST /api/auth/login`，字段是 8 位 `studentId`。会话存在进程内 `Map`，Cookie 名 `campus_session`。限流计数也在这个进程的内存里，重启后清零。分桶顺序在 `main` 的提交说明里是：已登录学号，Cloudflare Access 身份，然后是这次请求已经带上的 `campus_session`，都没有时才看来源地址。

演示身份是代码里的三档：普通学生、校集团队、平台管理员。`PUBLIC_MODE` 为 `1` / `true` / `yes` / `on` 时关掉切换，并拒绝 `POST /api/session`。

## 目录

```
server.cjs              启动
lib/                    服务端模块、种子、地点快照、校园范围
dist/                   node server.cjs 实际提供的页面
tests/                  node --test 的用例（main 上 15 个 *.test.cjs）
tools/provenance-dry-run.cjs
imports/                已入库的公开来源整理和审核记录，不是本机 data/store.json
config.example.json     配置字段示例，值为空
deploy/                 Caddy、nginx、systemd、launchd、备份，以及 Render 说明
render.yaml             Render Blueprint
ocr_canteen.py          食堂菜单 OCR 的 Python 脚本，不参与 node server.cjs
index.html              不由服务提供的投稿表单
site-dist/              另一份投稿表单
打开原型.command         执行 node server.cjs --open
```

`.gitignore` 排除 `config.local.json`、`config.json`、`.env`、整个 `data/`、`node_modules/`。互助登记和登记图片即使写在 `data/` 下也不会被提交。

`data/` 在克隆后不存在。知识库、互助账号、调用计数都是运行时写到这里的。Render 免费实例不能挂持久磁盘，这份 Blueprint 也没有挂，所以云上重启或重新部署会回到 `lib/seed.json`，云端模型 Key 要放在 `CAMPUS_AI_*` 环境变量里。
