# 快速启动与测试

命令在仓库根目录执行。没有 npm 依赖，不要先跑 `npm install`。

## 启动 main

```bash
node server.cjs
```

浏览器打开 http://127.0.0.1:4173 。未设置 `HOST` 时只监听 `127.0.0.1`。Mac 上也可以双击 `打开原型.command`，它的内容就是 `node server.cjs --open`。

这一版是学号登录，没有海报首页。要看 PR 26 的首页和独立登录页，检出那条分支的最新头再执行同一条命令，并重启已经在跑的进程。不要用停在 `9455785a` 的旧目录判断新登录。

可选的语法检查：

```bash
node --check server.cjs
```

## 自动测试

```bash
node --test tests/*.test.cjs
```

测试使用临时数据，不读取、不写你机器上的 `data/store.json`。
