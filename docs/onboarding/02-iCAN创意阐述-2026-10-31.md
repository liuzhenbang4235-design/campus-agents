# iCAN 创意阐述（2026-10-31 交件稿）

下面正文是 2026-10-31 交给赛事的创意阐述，按当时的产品形态写的。当时登录是学号弹框，演示身份可以切换，主说明核对本是 2026-10-27 的公开 README。把它当作历史交件，不要改写成 2026-11 之后的现状。现状见 [00-接手审计事实.md](00-接手审计事实.md) 和 [01-产品说明-安全摘录.md](01-产品说明-安全摘录.md)。

校集是面向南京邮电大学通达学院的校园 Agent 平台：把周边吃喝玩乐怎么查、办事与学习资料问谁、同学之间怎么互助，接到同一本机可运行原型。场景设定在日常校园：学号登录进入学生端，可切换普通学生、校集团队与平台管理员，走完问、查、帮、审闭环。生活侧用公开地点库答周边问题；学习与办事侧做知识问答，资料默认待审通过后才入库；互助通达按语义匹配，双方同意再开聊，并可举报。AI 嵌入方式是本地检索先行，配置云端模型后需用户确认才发送；互助与私信先过本地违规词表，并可选用云端语义筛查。亮点是聚合、共创与可控。公开仓见 GitHub campus-agents。当前为演示原型，未接学校真实统一认证。
