## 必须分开写的缺口

- 独立登录页在 PR 26 的 `d717f5b7` 及之后，不在 `main`，也没有装到上述 Mac 预览。那台机器上互助登记展开后仍是学号、昵称、密码表。

- 忘记密码在 PR 26 的页面上有入口，点开只说明暂时不能自助找回，没有重置接口。
- 「保持登录」勾选后，同一次进程里的会话到期时间会拉长；会话表在进程内存中，重启服务后登录状态消失。见 [04-PR26行为与未完成项.md](04-PR26行为与未完成项.md)。
- 「海报不能放大」已经写进 2026-11-15 的 `2532c11`（海报不能拖走、不能点开成大图，浏览器自身缩放仍可用）。这项属于 PR 26，不属于本次文档改动。文档不代替那条分支上后续还可能再推的提交。
