# 口语周边查询

2026-09-24：生活助手现在可根据问题自动检索本地通达周边公开点位，无需先查地图或勾选本次地点结果。

支持示例：“通达附近有什么吃的？”“学校旁边哪里喝咖啡？”“通达周边周末去哪玩？”“学校附近五公里哪里看展？”默认学校中心3公里，明确指定时支持1、3、5公里。不使用个人定位，不请求高德或社交平台，不产生地图接口调用；启用豆包后发送回答仍需用户勾选云端确认。

仅生活助手启用。已有手动地图选择优先，自动查询不会使其临时结果过期。没有匹配点位时说明未收录，不推断附近没有，也不调用模型编造商户。学校规定、学习问题和明确远处目的地不自动变成附近搜索。

验证：原43项后端测试及2项意图测试通过；新增2项接口集成测试通过，覆盖云端确认、地图零调用、手动结果保留、跨助手隔离与空结果说明。真实豆包口语查询返回校内食堂及原地图引用，明确区分直线距离和步行距离。实际结果见verification-campus-chat.json。
